# AnalyticFlow

**AnalyticFlow** — это веб-приложение для обработки табличных данных на основе предопределённых сценариев аналитики. Пользователь загружает CSV/Excel файл, выбирает сценарий обработки данных и получает результирующий отчёт с визуализациями и рекомендациями.

## 🎯 Основная концепция

В отличие от традиционных No-code drag-and-drop конструкторов, AnalyticFlow опирается на **сценарные пайплайны** — предопределённые последовательности обработки данных с параметризуемыми шагами. Пользователь:

1. **Загружает датасет** (CSV или Excel)
2. **Выбирает сценарий** (например, "Инвентарный анализ")
3. **Настраивает параметры** через интерфейс (маппинг колонок, параметры алгоритмов)
4. **Получает дашборд** с таблицами, графиками и метриками
5. **Сохраняет конфигурацию** в проекте для повторного использования

## 📋 Функциональность

### Авторизация
- Регистрация новых пользователей с хешированием пароля
- Вход в систему с сохранением сессии

### Управление проектами
- Создание, переименование, удаление проектов
- Каждый проект изолирован и содержит свои датасеты и сохранённые сценарии
- История сохранённых конфигураций с датами

### Загрузка данных
- Поддержка форматов: CSV (с автоопределением разделителя), XLSX, XLS
- Валидация при загрузке, сообщения об ошибках
- Физические файлы хранятся на диске в структурированной папке, метаданные — в БД

## Сценарии анализа

### Инвентарный анализ
Классификация товаров и управление запасами:
- **ABC-анализ** — разбиение товаров по важности по выручке (A/B/C)
- **XYZ-анализ** — разбиение по стабильности спроса (X/Y/Z)
- **Прогнозирование** — три метода (Holt, SMA, Naive) выбираются по группе
- **Страховой запас** — расчёт по Z-score и Lead Time
- **Матрица ABC-XYZ** — матрица распределения товаров

Результат: таблица с рекомендациями по запасам, тепловая карта распределения.

### RFM-анализ
Сегментация клиентской базы и прогнозирование ценности клиентов:
- **RFM-сегментация** — расчёт Recency (давность покупки), Frequency (частота), Monetary (сумма трат) по каждому клиенту
- **Динамические сегменты** — пользователь сам задаёт границы перцентилей и названия сегментов (например, «Чемпионы», «Спящие»), с приоритетом по порядку
- **LTV-прогноз** — расчёт ожидаемой ценности клиента на заданный горизонт с учётом маржинальности
- **Маркетинговые действия** — привязка рекомендованного действия (скидка, подарок, консультация и т.д.) к каждому сегменту
- **Матрица R×F** — тепловая карта плотности клиентов по давности и частоте покупок

Результат: таблица клиентов с сегментом, LTV-прогнозом и рекомендацией, сводка по сегментам.

### Финансовый скоринг
Оценка кредитного риска дебиторской задолженности:
- **Профиль контрагента** — агрегация платёжной истории: средняя задержка платежа (DPD), текущий долг, концентрация риска, коэффициент собираемости
- **Скоринговая модель** — пользователь настраивает веса значимости факторов риска (просрочка, концентрация долга, дисциплина платежей)
- **Классы риска** — присвоение класса A/B/C/D с настраиваемыми границами баллов и стратегией работы с контрагентом
- **Expected Loss** — расчёт ожидаемых потерь на основе вероятности дефолта (PD) по каждому классу риска
- **Кредитные лимиты** — рекомендация безопасного лимита отгрузки в долг с учётом маржинальности бизнеса
- **Квадрант-матрица риска** — визуализация контрагентов по сумме долга и скоринговому баллу

Результат: реестр контрагентов с рекомендуемым лимитом и стратегией (предоплата / отсрочка / блокировка), сводка по классам риска.

Архитектура приложения построена так, что добавление новых сценариев не требует изменения core-логики — каждый сценарий представляет собой независимый пайплайн обработки данных с собственной конфигурацией и визуализацией результатов.

## 🚀 Быстрый запуск программы

### Требования
- Docker и Docker Compose
- Python 3.10+
- PostgreSQL 14+ (запускается в контейнере)
- Git

### Установка и запуск

#### 1. Клонирование репозитория
```bash
git clone https://github.com/SerenityFlaim/analytic-flow.git
cd analytic-flow
```

#### 2. Файл переменных окружения

Из склонированного репозитория скопируйте файл-шаблон `.env.example` в созданный
локально файл `.env`.

- Скопировать можно как с помощью графического интерфейса, так и с помощью команды:
`cp .env.example .env`

- Можно поменять значения переменных: `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`
При отсутствии изменений база данных создаётся с логином, паролем и именем базы данных по умолчанию.

#### 3. Запуск проекта

Запуск проекта осуществляется в терминале, открытым в корне проекта одной командой:
`docker-compose up -d --build`

#### 4. Открытие вэб-интерфейса

Перейдите в браузере по адресу `http://localhost:8501`


## 📖 Как использовать приложение

### Первый запуск

1. **Регистрация**: На странице авторизации заполни форму регистрации
2. **Создание проекта**: В сайдбаре нажми "➕ Новый проект" и дай ему название
3. **Загрузка данных**: В сайдбаре нажми "Выбрать CSV/Excel" и загрузи файл

### Запуск анализа

1. На главной странице нажми "Запустить сценарий" для нужного анализа
2. Укажи маппинг колонок — сопоставь колонки твоего файла с требуемыми параметрами
3. Настрой параметры расчёта сценария (значения полей, слайдеров, выпадающих списков)
4. Нажми "Выполнить расчёт"
5. Просмотри результаты в дашборде

### Сохранение результатов

После расчёта нажми "Сохранить результат в историю проекта". Это сохранит:
- **Конфигурацию** (маппинг, параметры)
- **Результаты** (таблицы, метрики)

### Повторное использование

1. В сайдбаре нажми "📁 Просмотр проекта"
2. В списке сохранённых сценариев нажми "📊 Просмотреть отчёт"
3. Появится аналитический дашборд сохранённого проекта
4. В списке сохранённых сценариев нажми "▶️ Загрузить и запустить"
5. Конфиг автоматически предзаполнит форму — можно изменить параметры и пересчитать
